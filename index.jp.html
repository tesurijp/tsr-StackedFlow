THE IDEA

計算の流れを、そのまま書く。

tsr.StackedFlow は、型付きスタックを扱う小さなライブラリ。複数の値を保持しながら、パイプラインを進められます。

01 / STACK

値の型を維持する

数値も文字列も、任意の順で積めます。関数に渡す値の型や個数が合わなければ、コンパイル時に検出されます。

02 / APPLY

いつもの関数で計算する

スタック専用の関数は不要です。通常の F# 関数へ値を渡し、返された結果を次の処理に使えます。

03 / FLOW

必要な場所で取り出す

dup や swap で値を整え、head で結果を取り出す。普段の F# コードの中に、必要な分だけ組み込めます。

FOLLOW THE STACK

ひとつずつ、流れをたどる。

コードの行を選ぶと、各段階のスタックを確認できます。上側がスタックの先頭です。
※ 固定サンプルの可視化です。F# 実行環境ではありません。

STACK / TOP FIRST
SMALL API, FLEXIBLE FLOW

積む。整える。適用する。

短い演算子でも、関数名でも。
用途に合わせて同じ操作を記述できます。

スタックの基本操作

push / |+値を先頭へ追加
dup / over先頭 / 2 番目を複製
swap / rot / drop交換 / 回転 / 削除
head / pop先頭値 / 値と残りを取得

関数をスタックに適用

unary / |!1 引数の関数
binary / |!!2 引数の関数
ternary / |!!!3 引数の関数
apply1 … apply10引数の個数を明示

さらに多くの引数には Caller モジュールを利用できます。詳細な仕様と API は GitHub の README ↗ をご確認ください。
