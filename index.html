THE IDEA

Write the way your calculation flows.

tsr.StackedFlow is a small library for typed stacks. Carry multiple values through a pipeline, with their types intact.

01 / STACK

Preserve every value’s type

Push numbers, strings, and other types in any order. Incompatible argument types or insufficient stack values are caught at compile time.

02 / APPLY

Apply the functions you know

Use ordinary F# functions without stack-specific wrappers. Pass values to a function and carry its result into the next step.

03 / FLOW

Return to your regular code

Arrange values with dup and swap, then extract the result with head. Use stack pipelines wherever they fit your F# code.

Core stack operations

push / |+Push a value onto the stack
dup / overCopy the top / second value
swap / rot / dropSwap / rotate / drop
head / popGet the top / top and remaining stack

Apply functions to the stack

unary / |!A one-argument function
binary / |!!A two-argument function
ternary / |!!!A three-argument function
apply1 … apply10Specify the argument count

Use the Caller module for larger argument counts. Explore the full API and behavior in the GitHub README ↗.
